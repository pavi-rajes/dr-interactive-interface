This dataset contains neural, kinematic and experimental data from mice performing a licking task in response to either visual or auditory stimulus that got switched across sessions. Data from the Allen institute of neural dynamics - Dynamic Routing project. 
Known gaps: The meaning of stimuli in the world and the behaviors they elicit vary with context. We reach for a cup of coffee in the morning but ask for decaf in the evening. Flexible behavior requires flexible signal flow in the brain. Circuits that couple a stimulus to an action in one context must be disengaged in other settings.  How are neuronal circuits reconfigured to dynamically route information for different tasks? Goal is to investigate the neural mechanisms of task-switching behaviors in mice. In one paradigm, we train mice to perform a sensory switching task in which they alternate, in blocks of trials, between listening versus looking for rewarded auditory and visual stimuli. Focus on hypothesis related to flexible behavior - how neural circuits dynamically route information for different tasks or contexts?

Each .nwb file contains recordings from one mice during one recording session. Mice are head fixed and are performing a visual-auditory cross-modal attention switching task with Neuropixels recordings. Files are formatted using NWB standards (https://nwb.org/about-nwb/). 

These 5 NWB files collectively represent a rich, multi-modal dataset for studying cross-modal attention switching in the mouse brain. The experimental design enables investigation of how hundreds of simultaneously recorded neurons across visual, auditory, prefrontal, hippocampal, and subcortical areas flexibly reroute sensory information based on behavioral context — with genetic cell-type identification via optotagging, comprehensive quality metrics for unit curation, and detailed behavioral and physiological covariates (running, pupil, facial movements) for controlling state-dependent modulation of neural activity.

These tables inside NWB are the most useful ones to look at. 
1. general — Session Metadata
The root container for each NWB file. Stores session-level provenance: the experimenter, institution (Allen Institute for Neural Dynamics), session date/time, and a description of the experimental protocol. Critically, session_start_time is the absolute time reference — every other timestamp in the file is in seconds relative to this anchor. The devices field catalogs the Neuropixels probes and behavioral cameras used. This is where you look to orient yourself to what happened in a given recording session.
2. subject — Animal Metadata
Each file corresponds to one recording session in one transgenic mouse. The genotype field is scientifically crucial: it specifies the Cre-driver line (e.g., Sst-IRES-Cre, Pvalb-IRES-Cre, Vip-IRES-Cre) crossed with a Cre-dependent opsin reporter (e.g., Ai32 for ChR2-EYFP). This determines which genetically-defined interneuron population expresses channelrhodopsin and can therefore be opto-tagged during the experiment — a key technique for linking genetic cell-type identity to electrophysiological function. Mice are head-fixed and water-restricted to motivate task performance.
3. electrodes — Neuropixels Recording Sites
One row per electrode channel across all Neuropixels probes in the session. Neuropixels 1.0 probes have 384 recording sites tiled along a thin silicon shank, enabling simultaneous recording from hundreds of neurons spanning multiple brain structures in a single penetration. Each channel is registered to the Allen Common Coordinate Framework (CCF) — a standardized 3D mouse brain atlas — via post-hoc histological reconstruction of the probe track. The structure and location fields give the Allen CCF acronym (e.g., VISp = primary visual cortex, AUDp = primary auditory cortex, CA1, SCig) for each site, enabling anatomically-informed analysis across sessions and animals.
4. units — Spike-Sorted Neurons
The core electrophysiology data. Each row is one putative neuron isolated by Kilosort 2.5 template-matching spike sorting from the raw extracellular voltage traces. This table contains:
Spike times: the fundamental data for computing PSTHs, firing rates, and neural correlations with task events.
Waveform features (half_width, peak_to_valley, repolarization_slope): biophysical signatures used for cell-type classification — narrow-spiking units (~<0.4 ms half-width) are typically PV+ fast-spiking inhibitory interneurons, while broad-spiking units are typically excitatory pyramidal neurons.
Quality metrics from SpikeInterface: isi_violations_ratio (refractory period contamination), presence_ratio (temporal completeness), amplitude_cutoff (spike detection completeness), d_prime and isolation_distance (cluster separation), snr, and the composite default_qc pass/fail flag. These are essential for filtering — poorly isolated units introduce noise into population analyses.
Anatomical coordinates (ccf_ap, ccf_dv, ccf_ml, structure): Allen CCF registration from probe-track histology.
Drift metrics (activity_drift, drift_ptp, is_not_drift): assess whether the neuron's relationship to the electrode was stable across the session — crucial for long recordings where tissue settling can cause apparent firing rate changes.
5. epochs — Session Phases
Each recording session is divided into distinct experimental phases: the Dynamic Routing behavioral task (the main cross-modal attention-switching paradigm, ~60-90 min), receptive field mapping (visual and/or auditory, ~10-20 min each), optotagging (~10 min), and spontaneous activity periods. The script_name field identifies the TaskControl subclass that ran each epoch (e.g., DynamicRouting1, RFMapping, Optotagging). This table is the map for segmenting the continuous neural recording into functionally meaningful periods.
6. trials — Dynamic Routing Behavioral Task
The richest behavioral table. Each row is one trial of a visual-auditory cross-modal go/no-go attention-switching task. The paradigm's core design:
The mouse is presented with visual (drifting gratings) or auditory (tones/noise) stimuli.
In visual-rewarded blocks, the mouse must lick to visual targets (GO) and withhold to auditory targets (NOGO); in auditory-rewarded blocks, the contingency reverses.
The rewarded modality alternates every ~60 trials across 4-6 blocks per session, demanding cognitive flexibility — the ability to update attentional strategy based on changing reward contingencies.
Key columns encode the full signal-detection-theory structure: is_hit, is_miss, is_false_alarm, is_correct_reject, plus trial-type classifiers (is_go, is_nogo, is_catch, is_target, is_nontarget) and context variables (block_index, is_block_switch, rewarded_modality). The is_opto flag marks trials with optogenetic inactivation for causal loss-of-function analysis. Timing columns (stim_start_time, response_time, reward_time) enable precise alignment of neural activity to behavioral events.
7. performance — Block-Level Behavioral Summary
Aggregated performance metrics per context block: hit_rate, false_alarm_rate, d_prime (within-modality discrimination), and critically cross_modality_dprime — the signature metric of the Dynamic Routing task measuring how well the mouse switches its behavioral strategy when the rewarded modality changes. This is the primary readout for assessing cognitive flexibility and the effect of optogenetic perturbations on task performance.
8. manipulator_positions — Probe Insertion Coordinates
3D coordinates of the motorized micromanipulator (NewScale) for each Neuropixels probe. The z axis (depth) indicates insertion depth (typically 3,000-6,000 um to span multiple brain structures). The last_movement_time is always negative (before recording), confirming at least 15 minutes of settling time to minimize mechanical drift artifacts.
