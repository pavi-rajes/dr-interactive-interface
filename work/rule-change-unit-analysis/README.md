# Goal
Identify units that respond specifically to rule changes (block switches between aud-rewarded and vis-rewarded contexts). Using the precomputed aligned spikes and trials, define for each block switch the early post-switch trials (e.g. the first 5 to 10 trials of the new block) and the late trials of the same block (steady state). For each unit compute firing rate in an analysis window (baseline and/or stimulus-evoked) on early vs late trials, separately for aud→vis and vis→aud switches, and test the difference with a nonparametric or permutation test with BH correction. Also produce a trial-by-trial firing profile around each switch (e.g. -15 to +30 trials) so the viewer can show adaptation dynamics.

Output `data/precomputed/rule_change_units.parquet` with one row per unit and switch direction: session, unit_id, structure, CCF coords, early rate, late rate, effect size, p-values, significance flag, and a combined "rule-updating" flag; plus `data/precomputed/rule_change_by_region.parquet` summarizing fractions per structure, and a per-unit switch-aligned trial profile table. Script at `code/analyze_rule_change_units.py`, with the trial counts and windows exposed as CLI arguments.

Verified facts: every session has 6 blocks (77 to 93 trials) with 5 switches (block 0 has no preceding rule); the first 5 trials of every block are `is_instruction` trials (rewarded-modality target with non-contingent reward, teaching the new rule); `is_block_switch` is True on trial 0 of blocks 1 to 5. Behaviourally, mice update their rule within about 5 to 15 trials: response rate to the previously-rewarded modality's target drops from 0.75 in trials 5 to 9 to about 0.1 by trials 20 to 29 (session 742903). `switch_direction` in `trials.parquet` is `aud_to_vis` or `vis_to_aud` for blocks 1 to 5 (NaN for block 0). Stimulus lasts 0.5 s; response window is about +0.06 to +1.0 s.

Design: a "rule-updating" unit fires differently in the early trials after a rule change than in the steady-state late part of the same block. Contrast early (trial_index_in_block < 15, including the 5 instruction trials) vs late (trial_index_in_block >= 30) within switch blocks (blocks 1 to 5), tested in two analysis windows: baseline (-1.5 to -0.06 s) and stimulus-evoked (0.0 to 0.5 s). Primary test: detrended within-block chunk permutation (5-trial chunks; permute early/late chunk labels within each block, preserving counts), which asks whether the first 3 chunks of a block differ from the late chunks more than random chunks do. Because the 5 instruction trials are all rewarded-modality targets, early trials are stimulus-enriched (about 55% target stimuli vs 22% late), which confounds the stimulus-evoked window; the evoked test is therefore run on rates residualized on stimulus identity x context (`stim_name` x `rewarded_modality`, per-session mean subtracted per trial) before detrending, with the un-residualized p kept as `ev_p_perm_raw`. Calibration uses a mid-block pseudo-switch (same test with "early" relabelled to trials 40 to 54) on all five sessions; prototyping gave a pseudo-null fraction of 6 to 13% per session (mean about 9%) against 15 to 23% for the real switch, so the screen is usable but modest, and the pseudo-null thresholds are set at mean <= 0.10 and max <= 0.15 across sessions. Note that with 2 or 3 switch blocks per direction, `min_consistency 0.8` effectively requires every block of that direction to agree in sign.

# Results

## Summary
`code/analyze_rule_change_units.py` screened all 6,685 QC-pass units for early-versus-late firing differences within switch blocks, per switch direction and pooled, in a baseline and a stimulus-evoked window, using the approved detrended (block, label)-stratified chunk permutation (5-trial chunks, 2,000 permutations, BH within each direction x window family). Runtime 3.4 s. 272 units (4.1%) are rule-updating on the pooled (`both`) rows, all of them via the baseline window: the residualized evoked family has no BH-significant unit (minimum q = 0.059; 762 units at raw p < 0.05 against a pseudo-switch null of about 8%), exactly the weak excess the plan reviewer predicted. Per direction, 139 units are rule-updating for aud→vis and 260 for vis→aud switches. The cross-session pseudo-switch calibration passes (baseline null mean 0.087 / max 0.117 vs real 0.189; evoked null mean 0.084 / max 0.110 vs real 0.114). Switch-aligned profiles (45 relative-trial positions per unit, direction and window) are saved for the viewer. The example figure shows PL and SSs units with sharp bursts in the first 5 to 10 trials after a switch that decay as the mouse adopts the new rule, and an MOs unit that is suppressed early and recovers late.
