# Goal
Build the Python Shiny application in `code/app.py` (runnable with `shiny run code/app.py`) that reads only from `data/precomputed/` via `config.PRECOMPUTED_DIR`. Two tabs:

Tab 1, context-dependent baseline shifts: left panel with selectors for session, brain region (structure), unit (filtered by region, showing only significant units by default with a toggle), and analysis window (baseline window start/end and PSTH bin size); shows a raster plot and a PSTH for auditory-rewarded blocks and for visual-rewarded blocks side by side (or overlaid), with the baseline window shaded. Right panel: the 3D brain from the brain3d component with dots for units with significant baseline shifts, colored by effect size, and the selected unit highlighted; clicking a dot selects that unit.

Tab 2, rule-change units: same layout with an additional context selector (switch direction: aud→vis, vis→aud, or both) and analysis window controls; rasters/PSTHs for early post-switch versus late-block trials within auditory and visual blocks, plus the switch-aligned trial-by-trial firing profile. Right panel: 3D brain with rule-updating units.

Include a README with run instructions and confirm the app launches and renders both tabs against the precomputed data.
